# Система керування комп'ютерним класом (СККК) — покроковий посібник користувача

Цей посібник написаний для звичайного вчителя, який **не має** спеціальних
знань з адміністрування комп'ютерних мереж. Тут простими словами пояснено, що
це за система, навіщо вона потрібна, як її встановити й запустити крок за
кроком, а також що робити, якщо щось не працює.

> **Обов'язково прочитайте перед використанням.** Окрім цього посібника є
> технічний опис і важливі застереження:
> - Технічний опис (README):
>   <https://github.com/gromko/skkk/blob/main/README.md>
> - Важливі застереження, відомі проблеми та відмова від гарантій (IMPORTANT):
>   <https://github.com/gromko/skkk/blob/main/IMPORTANT.md>
>
> Використовуйте систему **лише у школі, з дозволу адміністрації та попередньо
> повідомивши учнів**, що їхні екрани можуть переглядатися, а комп'ютери можуть
> блокуватися.

## 1. Для чого потрібна ця система

**СККК** — це невелика програма для керування комп'ютерним класом у межах
**однієї шкільної локальної мережі**. Вона дозволяє вчителю зі свого комп'ютера:

- бачити **екрани учнів** у вигляді невеликих зображень (мініатюр) у сітці;
- відкривати **збільшений перегляд** екрана окремого учня;
- **демонструвати свій екран** вибраним учням;
- надсилати **текстові повідомлення**;
- **передавати файли** учням (з журналом передач);
- показувати **відеофайл** на комп'ютерах учнів (відтворюється штатним
  відеоплеєром і автоматично видаляється після перегляду);
- відкривати **відео з YouTube** у браузері учня за посиланням;
- **блокувати комп'ютери** учнів (перекриття екрана + блокування миші й
  клавіатури) або блокувати **лише введення** без перекриття екрана;
- **блокувати вихід в інтернет** (локальна мережа при цьому лишається
  доступною, тому зв'язок з учителем не втрачається);
- **вимикати комп'ютери** учнів із відліком часу.

Це **навчальний прототип**. Він не є «прихованим стеженням»: на комп'ютері
учня видно, що працює агент, і учнів слід про це повідомляти.

## 2. З чого складається система

Система має дві частини:

- **«Вчительська» частина** — працює на комп'ютері вчителя. Це програма
  **`teacher`** (у Windows — `teacher.exe`). Саме з неї вчитель керує класом.
- **«Учнівська» частина** — працює на комп'ютерах учнів. Це декілька програм,
  які лежать у теці **`student`**:
  - **`student_agent`** — «агент учня»: підтримує постійний зв'язок з
    комп'ютером учителя і фактично виконує всі вказівки (показує екран,
    приймає файли, блокує тощо). Має працювати постійно у фоні;
  - **`skkk_student_setup`** — програма автоматичного налаштування
    учнівського комп'ютера (має зручне меню з кнопками);
  - **`netguard`** — окрема програма для керування доступом до **Інтернету**
    (блокування / розблокування). Для роботи їй потрібні права адміністратора.

На **обох** сторонах є **програма автоматичного налаштування**:

- на вчительській — **`skkk_setup`**;
- на учнівській — **`skkk_student_setup`**.

Ці програми перевіряють наявність потрібних бібліотек, доступність локальної
мережі, **відкривають потрібні порти у файрволі** та створюють (на вчительській
стороні) або імпортують (на учнівській стороні) **токен доступу**. На
учнівській стороні меню ще й додає потрібні програми до **автозавантаження**.

### Що таке токен і навіщо він

**Токен** — це спільний «пароль-ключ» у файлі `classroom_token.txt`, за
допомогою якого комп'ютер учителя й комп'ютери учнів упізнають одне одного.
**Токен має бути однаковим** на всіх комп'ютерах. Його створює програма
налаштування на вчительському комп'ютері, і потім цей самий файл
`classroom_token.txt` потрібно покласти на всі учнівські комп'ютери.

> **Увага.** Токен — це фактично ключ доступу до класу. **Нікому його не
> передавайте** й не публікуйте. Якщо файл із токеном потрапив до сторонніх —
> створіть новий і заново роздайте учням.

### Розкладка файлів після розпакування

Після розпакування архіву ви побачите приблизно таку структуру (на прикладі
Windows; на Linux і macOS назви без `.exe`):

```
SKKK-windows\
├── teacher.exe            <- програма вчителя (запускається на комп'ютері вчителя)
├── skkk_setup.exe         <- налаштування вчительського комп'ютера
├── shared_libs\           <- службові бібліотеки (не чіпати)
└── student\               <- ЦЮ ТЕКУ цілком копіюють на комп'ютери учнів
    ├── student_agent.exe
    ├── skkk_student_setup.exe
    ├── netguard.exe
    └── shared_libs\
```

> **Важливо.** Копіюйте **всю теку цілком** (разом із підтекою
> `shared_libs`). Програми не працюють, якщо витягнути лише один файл — вони
> потребують своїх бібліотек поряд.

## 3. Що потрібно, щоб усе працювало

1. **Комп'ютери в одній локальній мережі** — усі під'єднані до **одного
   роутера** (одна шкільна мережа).
2. **Не можна одночасно** використовувати Wi-Fi і кабель (Ethernet) на одному
   комп'ютері — оберіть **щось одне**. Інакше комп'ютери «не бачать» одне
   одного.
3. **Права адміністратора** на кожному комп'ютері (пароль адміністратора
   Windows або `sudo`-пароль у Linux) — потрібні для налаштування файрвола,
   синхронізації часу, автозапуску й керування Інтернетом.
4. **Дозвіл школи** та попередження учнів.

### Про операційні системи та версії

- Є готові збірки для **Windows**, **Linux** і **macOS (Apple Silicon — M1/M2 і
  новіші)**.
- Це версії для **64-бітних** операційних систем. Для старих 32-бітних
  комп'ютерів можна запустити систему безпосередньо з Python-файлів (див.
  розділ 9), але це вже потребує базових навичок.
- У межах одного класу комп'ютери можуть мати **різні** операційні системи —
  вони сумісні між собою.
- «Вчительським» комп'ютером може бути **будь-який**, на якому працює
  `teacher`.

## 4. Покрокова інструкція

Нижче — головний алгоритм. Кроки 2–3 виконуються **на комп'ютері вчителя**,
крок 4 — це копіювання теки, крок 5 — на **кожному комп'ютері учня**, і лише
потім (крок 6) запускається `teacher`.

> **Чому саме такий порядок?** Програмі вчителя потрібен токен, а учнівським
> комп'ютерам — уже готовий токен у теці `student`. Тому спочатку налаштовують
> комп'ютер учителя, потім роздають теку `student`, і тільки тоді запускають
> `teacher`.

---

### Крок 1. Завантажте та розпакуйте

1. Відкрийте сторінку завантажень:
   <https://github.com/gromko/skkk/releases>
2. Виберіть архів для вашої системи:
   - `SKKK-windows.zip` — для Windows;
   - `SKKK-linux.zip` — для Linux;
   - `SKKK-macos.zip` — для macOS (Apple Silicon).
3. Розпакуйте архів у зручну теку (наприклад, `Documents\SKKK` на Windows або
   `~/SKKK` на Linux).

**Якщо щось не так:**

- *Не вдалося розпакувати.* Скористайтеся архіватором (на Windows —
  вбудований «Проводник» або 7-Zip).
- *Linux: файли не запускаються подвійним кліком.* Можливо, файлам бракує
  позначки «виконуваний». Відкрийте файл його властивості й увімкніть
  «Дозволити виконання файлу як програми», або виконайте в терміналі:
  ```bash
  chmod +x teacher skkk_setup student/student_agent student/skkk_student_setup student/netguard
  ```
- *macOS: система не дає запустити застосунок.* Натисніть на файл правою
  кнопкою → **Відкрити** → підтвердьте **Відкрити** (так macOS дозволяє
  запуск програм з-поза App Store).

---

### Крок 2. Налаштуйте вчительський комп'ютер (`skkk_setup`)

Запустіть **`skkk_setup`** (у Windows — `skkk_setup.exe`): подвійний клік по
файлу.

Майстер послідовно перевірить і, за потреби, налаштує:

| Що перевіряється | Навіщо |
|------------------|--------|
| Версія Python | потрібна 3.10+ (у готових збірках уже вбудована) |
| Бібліотеки (tkinter, Pillow, ImageTk, mss) | для показу екранів і вікон |
| Локальна мережа | щоб комп'ютери бачили одне одного |
| Порти TCP 8765 і UDP 8766 | «двері», через які йде обмін даними |
| Фаєрвол | відкрити ці «двері», щоб зв'язок не блокувався |
| Синхронізація часу | однаковий час на всіх комп'ютерах |
| Токен доступу | **створити** `classroom_token.txt` |

Коли майстер попросить **права адміністратора** (вікно з полем для пароля або
системний запит UAC), він спершу пояснить, **навіщо** вони потрібні, і лише
потім попросить пароль. Це нормально — введіть пароль адміністратора.

Наприкінці майстер повідомить про успіх і запропонує одразу запустити
`teacher`. **Не погоджуйтеся** — спочатку треба налаштувати учнівські
комп'ютери (кроки 3–5).

Рядки журналу мають позначки: успіх — зелена галочка, невдача — червоний
хрестик, попередження — знак `!`.

**Якщо щось не так:**

- *Майстер просить пароль, а ви його не знаєте.* Зверніться до шкільного
  адміністратора — без прав адміністратора частину налаштувань виконати не
  вдасться.
- *Помилка про зайнятий порт (8765/8766).* Закрийте інші копії програми
  (зокрема раніше запущений `teacher`) і повторіть.
- *Попередження «локальна мережа недоступна».* Перевірте, що комп'ютер
  під'єднаний до мережі (кабель або Wi-Fi) і має адресу в локальній мережі.
- *Windows показує запит брандмауера.* Дозвольте доступ **лише для
  приватної/шкільної мережі**.

Після успішного налаштування поряд із `skkk_setup` з'явиться файл
**`classroom_token.txt`** — саме він і є «ключ» до класу.

---

### Крок 3. Скопіюйте токен у теку `student`

1. Знайдіть файл **`classroom_token.txt`**, створений на кроці 2 (він лежить
   поряд із `teacher`).
2. Скопіюйте його **у теку `student`** (поряд із `student_agent`).

Тепер тека `student` містить усе необхідне для учнівських комп'ютерів, зокрема
спільний токен.

**Якщо щось не так:**

- *Не знаю, де `classroom_token.txt`.* Він має лежати в тій самій теці, де
  `teacher` і `skkk_setup`. Якщо його немає — поверніться до кроку 2 і ще раз
  виконайте «Налаштування системи».
- *На учнівському комп'ютері згодом напише «токен не збігається» або
  «не знайдено».* Отже, файл токена туди не скопійовано, скопійовано не той
  файл, або токени відрізняються. Переконайтеся, що на всіх комп'ютерах лежить
  **однаковий** файл `classroom_token.txt`.

---

### Крок 4. Роздайте теку `student` на учнівські комп'ютери

Скопіюйте **всю теку `student`** на кожен учнівський комп'ютер. Це можна
зробити:

- через **мережний диск** (спільна папка в мережі);
- через **флешку** (USB-носій);
- будь-яким іншим зручним способом.

Головне — щоб на кожному учнівському комп'ютері була **та сама** тека
`student`, і щоб у ній лежав файл `classroom_token.txt`.

**Якщо щось не так:**

- *Копіювання займає багато часу.* Це нормально: тека містить бібліотеки й
  займає досить багато місця. Копіюйте теку **цілком**, зачекайте завершення.
- *Після копіювання на учнівському комп'ютері немає токена.* Перевірте, що ви
  копіювали всю теку `student`, а не лише окремі файли з неї.

---

### Крок 5. Налаштуйте кожен учнівський комп'ютер (`skkk_student_setup`)

На **кожному** комп'ютері учня:

1. Відкрийте теку `student` і запустіть **`skkk_student_setup`** (у Windows —
   `skkk_student_setup.exe`).
2. У вікні, що відкриється, натисніть кнопку **«Налаштування системи»**.
   Програма перевірить бібліотеки, мережу, файрвол, синхронізацію часу,
   **імпортує токен** (може запропонувати вибрати файл `classroom_token.txt` —
   укажіть його в теці `student`) і створить файл налаштувань.
3. Дочекайтеся повідомлення про успіх у журналі.
4. Натисніть кнопку **«Додати в Автозавантаження»** — тоді агент учня й
   `netguard` запускатимуться самі після входу в систему.

Кнопки меню `skkk_student_setup`:

| Кнопка | Що робить |
|--------|-----------|
| **Налаштування системи** | перевіряє/встановлює компоненти, мережу, файрвол, синхронізацію часу, дозвіл на вимкнення, імпортує токен |
| **Додати в Автозавантаження** | додає агента учня та `netguard` до автозавантаження |
| **Видалити з Автозавантаження** | прибирає їх з автозавантаження |
| **Запустити систему** | запускає `netguard` **з правами адміністратора** та агента учня |
| **Зупинити систему** | зупиняє `netguard` і агента учня (комп'ютер **не** вимикається) |
| **Перевірити параметри** | показує стан токена, налаштувань, мережі, файрвола, автозавантаження, процесів |

Під час налаштування програма попросить **пароль адміністратора** (він потрібен
для файрвола, синхронізації часу, автозапуску, керування Інтернетом і дозволу
на вимкнення по мережі) — пояснивши, навіщо.

Після «Налаштування системи» бажано натиснути **«Запустити систему»** (або
перезавантажити комп'ютер, якщо ви вже додали автозавантаження).

**Якщо щось не так:**

- *Не вдається встановити бібліотеки.* У готовій збірці бібліотеки вже
  вбудовані, тож цей крок зазвичай минає без проблем. Якщо ви запускаєте з
  Python-файлів — див. розділ 9.
- *Повідомлення «Модуль tkinter недоступний».* Це трапляється при запуску з
  Python-файлів (не зі збірки). Рішення — встановити системний пакет
  (див. розділ 9).
- *Немає кнопки/вікна, відкривається термінал.* Схоже, запущено не ту
  програму: для налаштування потрібен саме `skkk_student_setup`, а не
  `student_agent`.
- *Просить вибрати токен, а ви не знаєте де він.* Файл `classroom_token.txt`
  має лежати в теці `student` (крок 3).

---

### Крок 6. Запустіть програму вчителя й перевірте зв'язок

Тепер, коли учнівські комп'ютери налаштовані й на них працюють агент і
`netguard`, запустіть на своєму комп'ютері **`teacher`** (у Windows —
`teacher.exe`).

- Протягом приблизно **3 секунд** комп'ютери учнів мають **самі** з'явитися у
  вікні вчителя у вигляді карток із мініатюрами їхніх екранів.
- Внизу кожної картки видно ім'я комп'ютера учня.
- Стан кожного комп'ютера показується значками (блокування, введення,
  живлення, інтернет).

Якщо картки з'явилися — усе працює, можна керувати класом (розділ 5).

**Якщо щось не так:**

- *Комп'ютери учнів не з'являються у вікні вчителя.*
  1. Переконайтеся, що на учнівському комп'ютері **запущено агента**
     (`student_agent`) і що він не показує помилок. За потреби запустіть його
     кнопкою **«Запустити систему»** в меню `skkk_student_setup`.
  2. Переконайтеся, що токен **однаковий** на всіх комп'ютерах.
  3. Перевірте, що всі комп'ютери в **одній мережі** й не використовують
     одночасно Wi-Fi і кабель.
  4. Переконайтеся, що файрвол пропускає порти (кнопка **«Налаштування
     системи»** на учнівському комп'ютері відкриває потрібний порт).
- *Агент пише «Вчителя не знайдено».* Зачекайте — агент періодично шукає
  вчителя й перепідключається. Якщо не допомагає, скористайтеся підказками
  розділу «Вчителя не знайдено» (розділ 6).

## 5. Коротко про керування класом

У вікні `teacher` учні позначаються галочками на картках. Кнопки згруповано у
блоки.

**Вибір:**
- **Усі** / **Зняти** — позначити або зняти позначки з усіх комп'ютерів.

**Керування виділеними комп'ютерами:**
- **Показати мій екран** — демонстрація вашого екрана вибраним учням;
- **Повідомлення** — надіслати текст;
- **Надіслати файли** — передати файли учням;
- **Перегляд відеофайлу** — надіслати й відтворити відео у учнів;
- **Відео з YouTube** — відкрити посилання у браузері учнів;
- **Блокувати** / **Розблокувати** — перекрити екран і заблокувати введення;
- **Блокувати введення** / **Розблокувати введення** — лише миша й клавіатура;
- **Вимкнути** — вимкнення з відліком;
- **Блокувати Інтернет** / **Розблокувати Інтернет** — без розриву локальної
  мережі.

**Інфо:**
- **Журнал передачі файлів**, **Журнал повідомлень**, **Загальна інформація**.

> **Порада.** **Клік по картці учня** відкриває велике вікно з його екраном
> (оновлюється наживо). Там є кнопка **Зберегти знімок…** і закриття вікна
> (кнопка **Закрити** або клавіша **Esc**).

## 6. Типові проблеми та їх усунення

### 6.1 Комп'ютер учня не з'являється в учителя / «Вчителя не знайдено»

Автопошук використовує «широкомовні» повідомлення в мережі, які часто блокує
файрвол або мережа. Перевіряйте по порядку:

1. Переконайтеся, що всі комп'ютери в **одній підмережі** й бачать одне одного.
2. Перевірте, що токен **однаковий** (той самий файл `classroom_token.txt`).
3. Переконайтеся, що **фаєрвол** пропускає потрібні порти — скористайтеся
   кнопкою **«Налаштування системи»** на обох сторонах.
4. Не використовуйте **одночасно Wi-Fi і кабель**.
5. Перезапустіть програму на боці вчителя.
6. Якщо у вчителя **декілька мережевих інтерфейсів** (кабель + Wi-Fi +
   віртуальні мережі від VMware/VirtualBox) — широкомовлення може йти «не тим»
   інтерфейсом. Найпростіший вихід — **USB-Wi-Fi** вимкнути, лишити один
   інтерфейс.
7. **Найшвидший спосіб обійти проблему** — вказати агентові адресу вчителя
   вручну (потрібні базові навички, див. README):

   ```
   student_agent 192.168.1.10
   ```

   де `192.168.1.10` — адреса комп'ютера вчителя.

### 6.2 Захоплення екранів не працює / чорні зображення

- Переконайтеся, що на комп'ютері учня є **активний графічний сеанс** (учень
  має бути в системі, а не на екрані входу).
- На Linux найнадійніше працює сеанс **X11**. У сеансі **Wayland** захоплення
  екрана може бути обмежене — перевірте це на цільових машинах.

### 6.3 Блокування введення (миша/клавіатура) не працює

- Блокування введення залежить від можливостей операційної системи. На
  **Wayland** і частині конфігурацій воно **недоступне** — у такому разі агент
  чесно повідомляє про це вчителю.
- На Linux обирайте сеанс **X11**; якщо блокування введення недоступне,
  користуйтеся звичайним **блокуванням** (з перекриттям екрана).

### 6.4 Блокування Інтернету не діє

- Потрібні **права адміністратора** (на Linux — `iptables`, на Windows —
  брандмауер Windows Defender). Запускайте `netguard` з правами адміністратора
  (кнопка **«Запустити систему»** або автозавантаження).
- Якщо `netguard` не підключений, учитель побачить попередження «Немає
  netguard — блокування не застосовано».
- Блокується саме вихід в **Інтернет**; локальна мережа та зв'язок з учителем
  залишаються доступними.
- **Пам'ятайте:** поки Інтернет заблоковано, **відео з YouTube у браузері
  учня теж не відкриється**. Якщо потрібне відео з YouTube — спершу
  розблокуйте Інтернет.

### 6.5 Відео з YouTube не відкривається

- Перевірте правильність посилання (дозволені лише `youtube.com`, `youtu.be`,
  `youtube-nocookie.com` та їх піддомени).
- Переконайтеся, що **блокування Інтернету вимкнено** (див. 6.4).
- Переконайтеся, що на комп'ютері учня встановлений **браузер** і він
  відкривається загалом.

### 6.6 Файл не передається

- Перевірте **розмір файлу** (за замовчуванням до **200 МБ** на один файл) і
  тип.
- **Виконувані файли** (`.exe`, `.bat` тощо) заборонені за замовчуванням — це
  зроблено з міркувань безпеки.
- Перевірте, чи є **вільне місце** на диску учня.

### 6.7 Вимкнення комп'ютера учня не працює (Linux)

- Переконайтеся, що на учнівському комп'ютері виконано кнопку
  **«Налаштування системи»** (вона додає дозвіл на вимкнення). Після цього
  **перезапустіть агента** (кнопки «Зупинити систему» → «Запустити систему»).
- Якщо у вікні вчителя з'явилася помилка про `libcrypto`, `OPENSSL` або
  `shared_libs` — це відома проблема **старої збірки**. Завантажте **свіжу**
  збірку зі сторінки релізів (або скористайтеся Python-версією). Деталі — в
  `IMPORTANT.md`, розділ 5.2.

### 6.8 Після збою вчителя комп'ютери учнів лишаються заблокованими

- Це очікувано: за замовчуванням розрив зв'язку не знімає блокування (так
  надійніше під час уроку). Розблокуйте комп'ютери, коли знову запустите
  `teacher`.
- За потреби досвідчений адміністратор може налаштувати автоматичне
  розблокування через певний час (див. `lock_failsafe_minutes` у README).

### 6.9 Загальні поради

- Спробуйте спочатку на **двох комп'ютерах**, перш ніж розгортати на весь клас.
- Перезапуск програми часто вирішує тимчасові збої зв'язку.
- Якщо помилка повторюється — сфотографуйте вікно з повідомленням і
  зверніться до адміністратора школи або до автора проєкту.

## 7. Як зупинити або прибрати систему

**Зупинити роботу (без видалення):**

- на вчительському комп'ютері — просто закрийте вікно `teacher`;
- на учнівському — відкрийте `skkk_student_setup` і натисніть
  **«Зупинити систему»**.

**Прибрати автозапуск:**

- на кожному учнівському комп'ютері відкрийте `skkk_student_setup` і натисніть
  **«Видалити з Автозавантаження»**.

**Повністю видалити систему:**

- видаліть теку `student` з учнівських комп'ютерів, а теку з `teacher` — з
  вчительського;
- зверніть увагу: програма вносила **системні зміни** (правила файрвола,
  автозапуск, дозвіл на вимкнення, завдання `netguard`). Їх бажано прибрати
  (кнопкою «Видалити з Автозавантаження» та вручну — докладно в `IMPORTANT.md`,
  розділ 3).

## 8. Безпека та законність (прочитайте обов'язково)

- Використовуйте систему **лише** в **авторизованій шкільній локальній
  мережі**, з дозволу адміністрації та **попередивши учнів**.
- **Ніколи** не використовуйте систему через Інтернет, VPN, публічні або
  гостьові Wi-Fi мережі.
- Дані передаються мережею **без шифрування**. Тримайте токен у таємниці.
- Використання системи для прихованого стеження або керування чужими
  пристроями **без згоди є незаконним**. Відповідальність за дотримання
  законодавства та правил школи лежить на користувачеві.

Детальніше — в `IMPORTANT.md` (розділи 1–4 та 6).

## 9. Додатково: запуск із Python-файлів (для досвідчених)

Якщо готові збірки не підходять (наприклад, дуже старий 32-бітний комп'ютер),
систему можна запустити безпосередньо з Python-файлів, завантажених із GitHub.

Потрібно:

- встановити **Python 3.10+** на кожному комп'ютері;
- на комп'ютері вчителя виконати:
  ```bash
  python -m pip install Pillow
  ```
- на кожному комп'ютері учня виконати:
  ```bash
  python -m pip install mss Pillow
  ```
- за потреби настановити `tkinter` (окремий системний пакет; на
  Debian/Ubuntu/antiX):
  ```bash
  sudo apt install python3-tk python3-pil.imagetk
  ```

Далі програми запускаються так:

```bash
python skkk_setup.py            # налаштування комп'ютера вчителя
python teacher.py               # програма вчителя
python skkk_student_setup.py    # налаштування комп'ютера учня
python student_agent.py         # агент учня
sudo python3 netguard.py        # керування Інтернетом (з правами адміністратора)
```

Усі деталі, аргументи командного рядка та додаткові можливості описано в
**README**.
